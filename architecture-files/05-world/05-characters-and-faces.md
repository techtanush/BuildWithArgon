# 05 — Characters, Faces and Lip-Sync

Characters are **stylized and procedural**: built from primitives in `npc/Character.ts` from a
`FaceSpec` that Argon generates for each agent. Portraits for the HUD/dashboard are generated by
Nano Banana from the same spec, so the 3D character and the portrait match.

## FaceSpec (`npc/FaceSpec.ts` and `kernel/data/faces.json`)

```ts
export interface FaceSpec {
  agent_id: string;
  skin: SkinTone;            // one of SKIN below
  hair_style: 'short' | 'buzz' | 'bob' | 'long' | 'bun' | 'curly' | 'ponytail' | 'bald' | 'mohawk' | 'waves';
  hair_color: string;        // hex, from HAIR_COLORS
  eye_color: string;         // hex, from EYE_COLORS
  brow: 'straight' | 'arched' | 'thick';
  nose: 'button' | 'round' | 'long';
  accessory: 'none' | 'glasses_round' | 'glasses_square' | 'headset' | 'hard_hat' | 'beanie' | 'earrings' | 'scarf' | 'visor' | 'bowtie';
  outfit: 'hoodie' | 'blazer' | 'overalls' | 'sweater' | 'vest' | 'jacket' | 'apron' | 'lab_coat';
  outfit_color: string;      // hex; department color or a darker/lighter variant of it
  pants_color: string;       // hex
  height: number;            // 0.92 … 1.08 (scale)
  build: number;             // 0.90 … 1.10 (width scale)
  names: { skin: string; hair: string; eyes: string; outfit: string; accessory: string }; // for portrait prompts
}
export const SKIN = ['#F6D7C3', '#EDC1A0', '#D9A37E', '#B97A56', '#8D5A3B', '#5E3A26'] as const;
export const HAIR_COLORS = ['#1E1B18', '#3B2A20', '#6B4226', '#A0612E', '#D9B26A', '#B7B7B7', '#7A3B6E', '#2F5D8A'];
export const EYE_COLORS = ['#3B2A20', '#5B7A3A', '#3E6C9E', '#6B4F2A', '#2B2B2B'];
```

### Generation (`worldgen/faces.py`, job `face_spec`, Argon medium)

One call for all agents. Prompt includes: the enums above, each agent's id/name/title/department/
department color/persona, and rules:
- Variety: within a building, no two agents share `hair_style`+`hair_color`; across the town, each
  `hair_style` used ≥ 2 times; skin tones spread across all 6 values.
- Role hints: engineering builder may wear `hard_hat` or `apron`; QA `glasses_square`; support
  `headset`; finance `blazer`; research `glasses_round` or `lab_coat`; concierge `scarf` or `bowtie`
  with `outfit_color` `#F5D90A`-family.
- Output ONLY a JSON array of FaceSpec objects.

Validation: enum membership, hex format, numeric ranges; repair once; else deterministic fallback
from `face_seed` (`mulberry32(face_seed)` picks every field). Write `kernel/data/faces.json`.

## Character construction (`npc/Character.ts`)

All sizes × `height` vertically and × `build` horizontally. Front faces local +Z.

| Part | Geometry | Position (y) | Material |
|---|---|---|---|
| Legs ×2 | `CapsuleGeometry(0.09, 0.62, 4, 12)` | center 0.40, x ±0.11 | pants color, roughness 0.8 |
| Shoes ×2 | `RoundedBoxGeometry(0.16, 0.08, 0.26, 2, 0.04)` | 0.04, z +0.03 | `#2A2A2E` |
| Torso | `RoundedBoxGeometry(0.46, 0.62, 0.27, 3, 0.08)` | 1.05 | outfit color, roughness 0.85 |
| Outfit details | hoodie: half-torus hood at back; blazer: 2 thin lapel boxes + shirt strip; overalls: 2 straps + bib; apron: front plane; lab_coat: longer torso to 0.62; vest: darker front panel; sweater: collar torus; jacket: zipper strip | — | outfit / derived |
| Arms ×2 | `CapsuleGeometry(0.065, 0.48, 4, 10)`, pivot at shoulder (±0.29, 1.32), rest angle z ±0.08 | — | outfit color |
| Hands ×2 | `SphereGeometry(0.06, 12, 10)` at arm end | — | skin |
| Neck | `CylinderGeometry(0.06, 0.065, 0.08)` | 1.40 | skin |
| Head | `SphereGeometry(0.19, 28, 20)` scaled (1, 1.08, 1) | 1.56 | skin, roughness 0.7 |
| Eyes ×2 | white `SphereGeometry(0.032)` at (±0.066, 1.60, 0.162); pupil `0.02` (eye color) +0.015 z; highlight `0.006` white | — | white roughness 0.2 |

| Nose | button: sphere 0.025; round: sphere 0.032; long: capsule 0.018×0.04 rotated | (0, 1.555, 0.19) | skin ×0.95 |
| Mouth | group at (0, 1.49, 0.176): cavity = `SphereGeometry(1, 16, 10)` scaled (w/2, open/2, 0.012), color `#5A2A2A`; upper lip and lower lip = `CapsuleGeometry(0.008, w, 4, 8)` rotated horizontal, skin ×0.85, positioned at ±open/2; teeth = white box (w×0.7, 0.012, 0.005) visible when open > 0.03 | — | — |
| Hair | per style from spheres/capsules/boxes/torus (short: hemisphere cap r 0.2; buzz: cap r 0.195 thin; bob: cap + side rounded boxes to jaw; long: cap + back rounded box to shoulders; bun: cap + sphere r 0.08 at back-top; curly: 16 spheres r 0.06 around the cap; ponytail: cap + capsule hanging back; bald: none; mohawk: 6 small boxes along the top; waves: cap + 3 torus segments) | — | hair color |
| Accessory | glasses: 2 torus rims + bridge (`metal_dark`); headset: torus band + 2 cups + mic capsule; hard_hat: half-sphere + brim (`#F5B400`); beanie: half-sphere + ribbed torus; earrings: small gold spheres; scarf: torus at neck; visor: curved plane; bowtie: 2 cones | — | — |

Merge static parts per material with `BufferGeometryUtils.mergeGeometries` (keep head, eyelids,
mouth, arms as separate animated objects). Shadows: cast on. Target ≤ 12k triangles per character.

## Animation (`npc/Character.ts`, updated each frame)

| Behavior | Rule |
|---|---|
| Breathing | torso `scale.y = 1 + 0.012·sin(1.6t + φ)` (φ random per agent) |
| Idle sway | root `rotation.z = 0.01·sin(0.9t + φ)` |
| Blink | every 2.5–5.5 s (random), eyelids close over 60 ms, open over 80 ms |
| Look at player | if player within 6 m: head yaw toward player clamped ±60°, pitch ±20°, smoothing `1 − exp(−8·dt)`; if yaw > 50° for > 1 s, rotate body toward player at 2 rad/s |
| Listening (V held) | head tilt `rotation.z = 0.08`, brows up 0.008 |
| Thinking | eyes glance up-left (pupils offset), one hand to chin (arm rotation) |
| Talking | mouth from visemes; head nod `rotation.x = 0.035·sin(7t)·envelope`; gesture arm `rotation.x = −0.25 + 0.15·sin(2.2t)` during sentences, relax at punctuation pauses |
| Greeting | small wave (right arm raise to 2.4 rad, oscillate 3 Hz for 1 s) on engagement |

## Lip-sync (`npc/LipSync.ts`, `npc/visemes.ts`)

Mouth parameters: `open` (meters, 0–0.07) and `width` (0.05–0.10).

| Viseme | Characters (after `toLowerCase()` and NFD diacritic strip) | open | width |
|---|---|---|---|
| A | a, h | 0.065 | 0.085 |
| E | e, i, y | 0.035 | 0.100 |
| O | o | 0.055 | 0.060 |
| U | u, w, q | 0.030 | 0.050 |
| M (closed) | m, b, p | 0.000 | 0.070 |
| F | f, v | 0.012 | 0.080 |
| C (consonant) | l, n, t, d, s, z, c, k, g, j, r, x, digits | 0.025 | 0.075 |
| Rest | whitespace, punctuation, anything else | 0.004 | 0.072 |

Driver, per frame while audio plays:
1. **With alignment** (ElevenLabs): `t = audio.currentTime`; binary-search the char index `k` with
   `starts[k] ≤ t < ends[k]`; target = viseme of `chars[k]`; blend 30% toward the next char's viseme
   when within 40 ms of `ends[k]`.
2. **Without alignment** (Gemini TTS): `AnalyserNode` (fftSize 1024) RMS of time-domain data →
   `open = clamp((rms − 0.02) · 0.9, 0, 0.07)`, `width = 0.075 − open · 0.2`.
3. **Browser speech**: `onboundary` events set a "word active" window of 180 ms; inside it,
   `open = 0.03 + 0.03·|sin(2π·9·t)|`; else rest.
Smoothing: `value += (target − value) · (1 − exp(−25·dt))`. When audio ends: ease to Rest over 120 ms.

Unit tests (`tests/unit/visemes.test.ts`): mapping table; binary search over a fixture alignment;
smoothing converges; diacritics ("é" → E).

## Portraits

Generated offline from FaceSpec (see [`../02-models-and-integrations/07-nano-banana-assets.md`](../02-models-and-integrations/07-nano-banana-assets.md)).
Missing portrait → the HUD renders a live 3D "portrait" by rendering the character's head into a
256×256 offscreen render target once (`npc/portraitFallback.ts`).
